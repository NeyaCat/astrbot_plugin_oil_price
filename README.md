# ⛽ astrbot_plugin_oil_price（全国油价）

一个 AstrBot 插件：每天自动抓取全国各省成品油挂牌价，分析今年 / 本月 / 本周最低价，
生成**涨红跌绿**的竖版长图按需推送；也能查单省单油号油价、按今日挂牌价算油费。

> 所有交互都走斜杠指令，不做自然语言关键字监听 —— 机器人不会在你聊天时插话。
> 定时推送的目标会话需要先加入白名单。

## 🚀 功能介绍

- **每日自动抓取**：默认每天 **07:05**（跟随 AstrBot 全局时区，时间可配）拉取全国 31 省全标号油价入库，并把「播报地区 × 所配标号」的日报图推送到白名单会话。
- **历史数据一键初始化**：`/油价初始化` 或设置页按钮，直连东方财富回填**今年全国 31 省**数据，跑完会在会话里回执（写入条数 / 调价事件数 / 耗时）。
- **全新部署自动初始化**：装好后**无需任何手动操作**，插件检测到空库且从未初始化过时会在后台自动跑一次历史初始化（开箱即用）；进度可在设置页看到，也可随时用上述指令重跑。
- **`/今日油价` · 整体播报**：播报地区 × 多标号的日报图，涨=红、跌=绿，不带加油建议。
- **`/看看油价 广东 92` · 单省单号**：一张竖图，价格牌 + 六行指标（较上次调价 / 调价日期 / 今年最低 / 当月最低 / 本周最低 / 下次调价）+ **加油建议内嵌同图**。
- **`/我要加油 30升` / `300元`**：按今日挂牌价精确换算，出「加油机结算单」图。
- **记住常用地区与油号**：`/油价设置 广东 92` 一次设好两项，之后两条查询指令可省略参数；**纯本地偏好，不触发任何抓取**。
- **调价日提醒**：识别到当天为调价日时，额外推送一条涨跌提醒（每天最多一条）。
- **收到指令先贴一个 👌**：出图要联网补数据 + t2i 渲染，群里可能等好几秒，先给个回执免得干等。
- **图片主题自动切换**：按**北京时间**当日晨昏点出浅色 / 深色，无需也不提供手动配置。
- **网页查询界面（可选）**：浏览器打开 `http://<host>:9852/`，多选查油价、单选算油费，还能记住上次的选择。
- **HTTP 取图接口（可选）**：独立端口返回图片二进制，方便脚本 / 面板 / 壁纸工具调用。
- **图片页头背景可换**：设置页上传 JPEG / PNG / WebP，自动压缩到 512 KB 内，也可一键恢复默认雪山。

## 📦 环境要求

| 项目 | 要求 |
| --- | --- |
| AstrBot | **≥ 4.9.2**（依赖 KV 存储与 `html_render`） |
| t2i 服务 | **必须启用** —— 三种业务图都靠它渲染，**不做纯文本降级** |
| Python | 3.10+（随 AstrBot 运行时） |
| 依赖库 | `httpx`、`tzdata`、`Pillow>=10.4`（`aiohttp` 由 AstrBot 运行时提供） |

- 数据源联网：ShowAPI（可选，需 appKey）与东方财富 datacenter（无需鉴权）。
- 无需 git、无需克隆任何仓库，历史初始化全部走 HTTP 接口。

## 🔧 安装

1. 把整个 `astrbot_plugin_oil_price/` 放到 `AstrBot/data/plugins/` 下。
2. 重启 AstrBot，或在 WebUI 插件页点击「重载插件」。
3. 打开插件详情页 → 「全国油价」设置页，填写 ShowAPI appKey 并选择播报地区。
   appKey 到 [showapi.com（万维易源）](https://www.showapi.com/) 注册后，在「控制台 → 我的应用」创建应用即可看到（设置页里也直接给了这个地址）。
   **不填也能用**：每日抓取会自动降级到东方财富，历史初始化本来就是东方财富，不受影响。
4. **配置推送白名单**（见下文）—— 不填则每日定时推送不会发出，指令照常可用。
5. **完成**。全新部署会自动初始化：插件启动时若发现库是空的、且从未成功初始化过，会在后台自动拉取今年全国 31 省历史数据（几分钟内完成，进度见设置页），**不需要再手动点按钮**。想重跑或补数据时，才用设置页的「初始化全国历史数据」或 `/油价初始化`。

## 🎮 使用方法

### 指令一览

| 指令 | 权限 | 说明 |
| --- | --- | --- |
| `/今日油价` | 普通 | 整体播报图（播报地区 × 多标号），**不带参数** |
| `/看看油价 [省份] [油号]` | 普通 | 单省 + 单油号大图，加油建议**内嵌**同图；两项都可省（用偏好） |
| `/我要加油 数量 [省份] [油号]` | 普通 | `30升` 算金额、`300元` 算升数；省份油号可省（用偏好） |
| `/油价设置 [省份] [油号]` | 普通 | **一次设好两项**；只写一项就只改那一项 |
| `/油价设置地区 省份` | 普通 | 保存常用省份（写 `广东省` 这类写法会自动归一） |
| `/油价设置油号 标号` | 普通 | 保存常用油号 |
| `/油价刷新` | 管理员 | 立即抓取一次今日油价（全国 31 省） |
| `/油价初始化` | 管理员 | 启动**全国 31 省**历史初始化，完成后在该会话回执结果 |
| `/油价推送` | 管理员 | 立即按白名单推送一次 |
| `/油价订阅` | 管理员 | 把当前会话加入白名单 |

### 参数写法

参数一律**顺序自由**、可省略（省略项由偏好补齐），中文全角数字与全角 `＃` 都会归一化：

```
/看看油价 广东 92  ==  /看看油价 92 广东  ==  /看看油价 广东 92#
/我要加油 30升 广东 92  ==  /我要加油 广东 92 30升  ==  /我要加油 30升
/油价设置 广东 92  ==  /油价设置 92 广东  ==  /油价设置 广东
```

- **标号一律写 `92#`**（图上也这么显示）。输入侧 `92` / `92#` / `92号` / 全角 `９２＃` 都认，被空格切成 `92 #` 也会拼回去。
- **省份支持城市别名**：`深圳` → `广东`（并回一句「深圳执行广东省统一油价」）。别名只在解析输入时生效，落库的一定是省级名。
- 形状对但内容不认（`火星`、`91`、`30斤`）一律回**具体文案**，说明该怎么办，不做静默回落（不猜默认标号、不退化为多油号）。

### 记住常用地区与油号

每个用户（按「平台 ID + 发言人 ID」记账）可以保存**一个常用省份**和**一个常用油号**，
保存后 `/看看油价`、`/我要加油` 都能省掉这两个参数。

- 三条设置指令**共用同一份偏好**，可以混着用，且每条**只改自己那一列** —— 改地区不会清掉已保存的油号。
- **指令里显式给出的参数优先于偏好**：临时查一次别处不必先改设置。
- 没保存过的用户第一次裸发 `/看看油价` 会收到「先设置地区」的引导，不会随手挑一个省份糊弄过去。
- 设置类指令**只写本地偏好，不触发任何抓取**，也不受时间闸门限制，随时可用。

### `/我要加油` 计算规则

```
/我要加油 30升            → 应付金额（用已保存的地区与油号）
/我要加油 30升 广东 92    → 广东 92#，应付金额
/我要加油 300元 广东 92   → 广东 92#，可加升数
```

- **数量必填且必须带单位**：算金额用 `升` / `公升` / `L`，算升数用 `元` / `块` / `圆` / `¥`。
- 上限：单次最多 **1000 升** / **100000 元**，数量最小 0.01。
- 结果是按挂牌单价的**精确换算（两位小数）**，不做向上取整、也不模拟加油站凑整 —— 实际结算规则因地而异，任何模拟都是假精确。
- 取价只读本地库，**不打 ShowAPI**（不受 1 QPS 限制、无 appKey 也能用）；价格日期不是今天时，图上会显式标注「非今日价格」。
- 标号**不受「最低价分析标号」配置限制**：想算 98# 只要库里有数据就能算。

## 🔔 推送白名单（必读）

推送白名单决定「每日定时推送发给谁」。指令本身不受白名单限制 —— 任何会话都能
`/今日油价`，机器人只是不会主动往没登记的会话里发消息。

| 配置项 | 格式 | 说明 |
| --- | --- | --- |
| `push_users` | `机器人名:QQ号` | 私聊白名单，每行一条 |
| `push_groups` | `机器人名:QQ群号` | 群白名单，每行一条 |

- **「机器人名」= 平台配置里的 `ID`**（WebUI → 平台配置 → ID），**不是**显示名称，也不一定是 `aiocqhttp`；默认值通常是 `default` 或 `aiocqhttp_default`。
- **两项都为空 = 不推送**：到点只抓取入库，不发消息（启动日志会给出 warning）。
- 号码必须是**纯数字**，非数字条目会被忽略并在日志中提示；半角 / 全角冒号都支持，也接受直接粘贴完整的 umo（`机器人名:FriendMessage:QQ号`）。
- **最省事的方式**：让管理员在目标群 / 私聊里发送 `/油价订阅`，插件会把当前会话自动写进对应白名单并回显写入的那一行。

> ⚠️ 从 v1.0.0 升级：旧配置 `push_targets`（umo 列表）会在插件启动时**自动迁移**到上述两项白名单并清空，无需手工处理。

## 🌐 网页查询界面与 HTTP 取图接口（可选）

默认**关闭**。开启 `http_api_enable` 后，插件会额外监听一个独立端口（默认 `0.0.0.0:9852`），
**直接返回图片二进制**，同时提供一个**网页查询界面**。

> ⚠️ 该接口**不走白名单过滤**：只要开启并知道地址，任何能访问该端口的人都能调取。
> 请仅在可信网络内使用，或把 `http_api_host` 改为 `127.0.0.1` 只允许本机访问。

### 网页查询界面

浏览器直接打开 `http://<host>:9852/` 就是查询页（`/index.html` 同效）：

- **查油价 · 多选**：地区与油号都是**可搜索的下拉多选框**（输入「深圳」也能搜到「广东」），选完点「查询油价」出一张多省多号图。
- **算油费 · 单选**：单选地区 + 单选油号 + 数量（填升数算花多少钱，填金额算能加多少升），出一张结算单图。
- **记住上次的选择**：地区 / 油号 / 数量 / 单位 / 停留的标签页都写进浏览器 `localStorage`（键 `oil-query-v1`），下次打开直接回显。只存选择，不存结果也不上传。
- 出图后可以直接「在新标签打开原图」或「复制图片直链」，贴到 Markdown / 群里都能用。

页面**完全自包含**（HTML/CSS/JS 与选项全部内联，不引任何 CDN，内网断网可用），并且
**只用相对路径**调本服务的接口 —— 所以把 `http://内网IP:9852/` 反向代理到
`https://你的域名/任意前缀/` 时，页面**不需要任何改动**：

```nginx
location /oil/ {
    proxy_pass http://127.0.0.1:9852/;   # 末尾的 / 会把 /oil 前缀剥掉
}
```

### 端点

端点与斜杠指令**一一对应**（`type` 只能是这三个值）：

| 端点 | 对应指令 | 说明 |
| --- | --- | --- |
| `GET /` | — | **网页查询界面**（多选查油价 / 单选算油费）；`/index.html` 同效 |
| `GET /oil?type=report&grades=92,95` | `/今日油价` | 整体播报图；可用 `province=` 限定单省，或 `provinces=北京,上海,广东` **多省** |
| `GET /oil?type=province&province=北京&grade=92` | `/看看油价` | 单省单油号图（含加油建议）。`province` 与 `grade` **都必填** |
| `GET /oil?type=calc&province=北京&grade=92&amount=30升` | `/我要加油` | 结算单图。三个参数**都必填**，`amount` 必须带单位 |
| `GET /health` | — | 运行状态 JSON（行数、日期数、时区、下次推送、白名单数量等） |
| `GET /help` | — | 用法提示 JSON |

- `grades` 与 `provinces` 都是**列表参数**，分隔符可用半角 / 全角逗号、顿号或空格；`provinces` 里写城市名会被归一到省级名，不认识的地名返回 `400`。
- **不读用户偏好**：接口没有用户上下文，缺必填项返回 `400` JSON 并说明缺哪一个。
- 出图使用本地临时文件并在返回后立即删除；渲染失败返回 `503` JSON。
- 端口被占用时只在日志中报错，**不影响插件其它功能**；修改地址 / 端口后会自动热重启监听。

```bash
curl -o oil.jpg "http://127.0.0.1:9852/oil?type=province&province=北京&grade=92"
```

## 🎨 图片主题：按北京时间晨昏点自动切换

主题**没有配置项** —— 出图时刻落在当日日出与日落之间就是 `light`（暖白数据台），
其余时间就是 `dark`（墨蓝夜间版）。判定基准固定为**北京时间**（UTC+8，不依赖 `tzdata`），
晨昏点按北京经纬度**逐日实算**（民用晨昏线，太阳中心地平高度 −0.833°）：

| 日期 | 日出 | 日落 |
| --- | --- | --- |
| 夏至 06-21 | 04:47 | 19:47 |
| 冬至 12-21 | 07:33 | 16:53 |

之所以算而不是写死 6:00 / 18:00：北京年内晨昏点摆动两个半小时以上，写死常量会在冬天
07:00（天还没亮）出浅色图、夏天 18:30（太阳还很高）出深色图。设置页「显示」一栏会回显
当前判定（含今日日出日落时刻），只读、不可改。

三张图统一为 **768px 宽、内容自适应高度**（手机上缩放后小字依然可读），共用同一套页头与
页脚；**涨=红、跌=绿**（中国习惯），琥珀是唯一强调色。

## 🗂️ 数据来源

| 用途 | 来源 |
| --- | --- |
| 每日各省油价 | ShowAPI `138-46`（不传 `prov`，一次取回全国 31 省，**全部入库**） |
| 调价日 / 涨跌 / 下次调价日期 | ShowAPI `138-49`（`prov` 必填，取「调价日基准省份」作为日期来源） |
| 个人查询缺当日数据 | 同上 `138-46`，按需补数据，**每省每个油价日最多一次**（见下文） |
| 历史初始化 | 东方财富 datacenter `RPTA_WEB_YJ_JH`（分省油价）/ `RPTA_WEB_YJ_BD`（调价记录），纯 GET、无需鉴权，**覆盖全国 31 省** |
| 每日降级来源 | 同上（ShowAPI 失败时自动改用东方财富，同样覆盖全国） |

- **数据源策略固定为「ShowAPI 优先，失败自动降级东方财富」，不可配**：这是唯一合理的组合 —— ShowAPI 覆盖 31 省全标号且带调价日，东方财富无鉴权、无额度限制，两者互为备份。
- **ShowAPI 只认 appKey 一种鉴权方式**（`?appKey=xxx`），appKey 在 [showapi.com（万维易源）](https://www.showapi.com/) 的「控制台 → 我的应用」创建应用即可拿到。
- **单位口径**：分省油价与涨跌为 **元/升**；东方财富的调价幅度（`QY_FD` / `CY_FD`）为 **元/吨**，入库时在 `adjustment_events.note` 中标注，两类数据不会混用。
- **免费额度**：每日仅需 1 次全省调用（138-46）+ 1 次调价日调用（138-49），用量很小；未配置 appKey 时每日抓取与历史初始化仍可完全依赖东方财富运行。

## ⏰ 定时与推送

- 默认时间 **07:05**，按 **AstrBot 全局时区**（系统配置 → 时区，默认 `Asia/Shanghai`）执行；比上游 7 点更新晚 5 分钟做缓冲，避免取到旧数据。
- 时区读取失败（配置为空或名称非法）时回落 `Asia/Shanghai`。
- 推送目标来自白名单；白名单为空时即使到点也不会发送任何消息。
- **闸门只看数据，不看时钟**：只要库里存着价格，`/今日油价`、`/看看油价`、`/我要加油`、`/油价推送` 一律照常出图；只有**空库**（首次部署 / 从未成功抓取）才回「暂无可用油价数据，将在每日 HH:MM 后自动抓取」，此时由管理员执行 `/油价刷新` 立即放行。

## ❓ 常见问题

**省份为什么只有 31 个？深圳在哪？**
国内成品油最高零售价由**省级**发改委发布，深圳执行的就是广东省的价格表，所以两个数据源
都只返回 31 个省级行政区。插件在指令侧额外认一层**城市别名**（省会 / 首府 + 计划单列市 +
常见地级市），`深圳` 会解析成广东；未收录的城市仍会提示「未识别的省份」并列出 31 个省级名 ——
不会瞎猜。**香港 / 澳门 / 台湾**属特别行政区 / 地区，数据源不覆盖，插件会明确回复「暂不支持」。

**「播报地区」是数据范围吗？**
不是。`provinces`（UI 上的「播报地区」）只决定 `/今日油价`、每日定时推送、HTTP `type=report`
这几张多省图**展示哪些省**；**历史初始化与每日抓取都覆盖全国 31 省**，`/看看油价`、`/我要加油`
也能查任意省。展示范围随便改，数据都在。

**为什么凌晨看到的是前一天的价？**
上游每天 **07:00 前后**才出当日牌价，所以从自然日零点到早上七点，「今天」的牌价还没诞生，
库里最新的仍是前一天那一份。插件会**照常出图**，但在图上标注数据日期
（「当前展示 2026-10-08 挂牌价 · 今日牌价于每日 07:05 前后更新」），只有在日期与当天不同时
才出现这行提醒。

**查询会白白消耗接口额度吗？**
不会。库里有当日价格就直接放行、零请求；确实缺数据时才会补一次，且**每个省份每个油价日最多
一次**（以 07:00 为油价日分界）。补数据时一次请求取回全国 31 省，顺手把其他省份也补齐；失败
也会记账，不给第二次机会（免费额度按次计）。设置类指令与 `/今日油价` 不补数据。

**图上的「涨跌」是今日涨跌吗？**
不是，**一律是「较上次调价」**。库里每天补一条快照行，但油价只在调价日变动，两次调价之间可能
隔十几天 —— 若按相邻两日差分就会显示「持平」，反而把「上次调价涨了 0.31」这件事盖掉。三种业务图
口径完全一致，图内页脚也写明这一点。

**历史数据的标号齐吗？**
东方财富报表只有 **89# / 92# / 95# / 0#**；98# / 97# / 93# / 90# 只能从插件启用之日起逐日累积，
图片中的最低价区块会标注数据范围。

**装好之后要手动点「初始化」吗？**
不用。检查到「库是空的**且**从未成功初始化过」时，插件启动会在后台自动跑一次历史初始化，
补齐今年全国 31 省数据 —— 这就是上面说的开箱即用。库里有数据或早就初始化过的实例两个条件
都不成立，行为与原样一致，**不会每次重启都重跑**。首次若因网络失败，会在下次启动自动重试；
想主动重跑走 `/油价初始化` 或设置页的「初始化全国历史数据 / 重新初始化」。

## 📝 重要说明

- **历史初始化是后台任务**：`/油价初始化` 只回一句「已开始」，东方财富分页拉取全国 31 省可能要好几分钟，**跑完会往触发它的会话再发一条结果**（写入条数 / 调价事件数 / 耗时；失败带上原因）。
- **自动初始化不发回执**：全新部署时的那次自举没有会话上下文（不是谁发的指令），所以只写日志、进度显示在设置页；失败原因看控制台 `[oil_price]` 前缀日志。
- **设置页进度会自动刷新**：页面加载即开始轮询（运行中 1s / 空闲 4s 一次，标签页隐藏时暂停），所以从聊天侧执行 `/油价初始化` 也会实时反映在面板上。
- **必须出图**：渲染失败会返回「出图失败」提示（HTTP 返回 503），**不降级成纯文本图**，避免版式不一致 —— 请确保已启用 AstrBot 的 t2i 服务。
- **图片页头背景**：设置页「显示 → 图片页头背景」可上传 JPEG / PNG / WebP，自动缩放压缩至 512 KB 内，保存在插件数据目录（重载与升级后保留），也可一键「恢复默认雪山」。
- **数据库位置**：`data/plugin_data/astrbot_plugin_oil_price/oil_price.db`（SQLite，WAL 模式，主键 `(date, province, grade)` 幂等去重）。
