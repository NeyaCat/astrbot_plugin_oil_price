数据源

每日抓取固定走「ShowAPI 优先，失败自动降级东方财富」—— 这是唯一合理的 组合，不再提供切换：ShowAPI 覆盖 31 省全标号，东方财富无鉴权、无额度限制， 两者互为备份。历史初始化固定直连东方财富、覆盖全国 31 省（无需 appKey）。

播报设置

「播报地区」只决定 /今日油价、每日定时推送与 HTTP type=report 出图时展示哪些省。它不限制数据范围：历史初始化与每日抓取都覆盖全国 31 省， 个人功能（/看看油价、/我要加油）查任意省、缺当日数据时自动补一次。

推送与白名单

白名单决定每日定时推送发给谁；填写在此的会话才会收到推送（指令不受限制）。 两项都为空时不推送。机器人名 = 平台配置里的 ID（不是显示名称）， 也可让管理员在目标会话里发送 /油价订阅 自动加入当前会话。

HTTP 取图接口

额外监听一个独立端口，直接返回图片二进制，方便脚本 / 面板 / 壁纸工具调用。 该接口不走白名单过滤：只要开启并知道地址，任何人都能调取， 请仅在可信网络内使用（或把监听地址改为 127.0.0.1）。
